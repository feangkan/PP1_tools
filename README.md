# PP1 Tools

Study toolkit for **PP1** — feed resources here, then ask the agent to summarise, diagram, check task requirements, answer questions from your materials, and build Chicago-style reference lists.

**Stigmergy (Rhino + browser guide):** see [`STIGMERGY-WHERE.md`](STIGMERGY-WHERE.md) → `02-assessment-tasks/assessment-1-development/`

## Folder map

| Folder | Purpose |
|--------|---------|
| [`01-project-info/`](01-project-info/) | Subject outline, learning outcomes, schedule, contacts |
| [`02-assessment-tasks/`](02-assessment-tasks/) | Briefs, rubrics, checklists, drafts |
| [`03-weekly-resources/`](03-weekly-resources/) | Week-by-week readings, slides, notes, links |
| [`04-summaries/`](04-summaries/) | Agent-generated or your own summaries |
| [`05-diagrams/`](05-diagrams/) | Weekly hybrid diagram packs + Assessment 1 diagrams + cross-week synthesis (`05-diagrams/synthesis/`) |
| [`06-references/`](06-references/) | Chicago (notes-bibliography) reference lists |
| [`07-q-and-a/`](07-q-and-a/) | Questions answered from your fed resources |
| [`08-diagram-style/`](08-diagram-style/) | Your hybrid diagram style + weekly 5-file pack rules |
| [`templates/`](templates/) | Copy-paste templates for each workflow |

## What you can ask the agent

1. **Summarise** — “Summarise week 2 readings into `04-summaries/`.”
2. **Weekly diagram pack** — “Make the week 1 pack (diagram, explanation, script, context, references).”
3. **Recheck requirements** — “Check my draft against the Assessment 1 rubric.”
4. **Answer from resources** — “Using only files in `03-weekly-resources/week-03`, explain X.”
5. **Chicago references** — “Build a Chicago bibliography from these sources.”

See [`HOW-TO.md`](HOW-TO.md) for step-by-step workflows.

## Quick start

1. Fill in [`01-project-info/SUBJECT_OVERVIEW.md`](01-project-info/SUBJECT_OVERVIEW.md).
2. Drop assessment briefs into [`02-assessment-tasks/`](02-assessment-tasks/).
3. Add weekly materials under [`03-weekly-resources/week-XX/`](03-weekly-resources/).
4. Ask Cursor (chat or cloud agent) using the prompts in `HOW-TO.md`.

## Conventions

- Prefer Markdown (`.md`) for notes and outputs.
- Put source PDFs/slides in the matching week folder; keep filenames clear (`lecture-slides.pdf`, `reading-smith-2020.pdf`).
- When the agent writes outputs, save them under `04-` / `05-` / `06-` / `07-` — do not overwrite your source materials.
- Citation style default: **Chicago notes-bibliography** (see `templates/chicago-reference.md`).

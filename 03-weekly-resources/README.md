# Weekly resources

One folder per teaching week. Start with weeks 1–6; add `week-07`, `week-08`, … as the semester continues.

## Layout per week

```
week-XX/
  README.md           # topic, goals, file index (copy from templates/week-readme.md)
  lecture-notes.md    # optional
  tutorial-notes.md   # optional
  readings/           # optional: PDFs, articles
  links.md            # optional: LMS / video links
```

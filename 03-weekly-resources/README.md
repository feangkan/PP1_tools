# Weekly resources

One folder per teaching week. Weeks 1–6 exist; add `week-07`, `week-08`, … as the semester continues (Week 7 = Assessment 2 development, no new lecture pack yet — see `05-diagrams/assessment-2/`).

## Layout per week

```
week-XX/
  README.md           # topic, goals, file index (copy from templates/week-readme.md)
  lecture-notes.md    # optional
  tutorial-notes.md   # optional
  readings/           # optional: PDFs, articles
  links.md            # optional: LMS / video links
```

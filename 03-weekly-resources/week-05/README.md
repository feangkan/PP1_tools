# Week 05 — Architecture and the Instruments of Law (The Building Code)

## Topic

The National Construction Code as an **instrument of law**, not only a compliance checklist: how buildings are classified and measured (class, type, height, light, ventilation); how the same “rational, empirical, ordered” logic appears in the Rebuilding of London Act 1666; and how architects move from **subject** of the code, to **interpreter**, to **co-author**. The three pre-readings (Lui, Hill, Fire/Water/Building) sit under this lecture.

Week 5 is also Assessment 1 verbal presentation (Monday) and final submission (Sunday 23 August 2026).

## Learning goals

- Read NCC provisions (classifications, construction type, room height, light, ventilation) as measurable translations of health, safety and amenity
- Distinguish Deemed-to-Satisfy / “standard” solutions from performance / “bespoke” demonstration with other experts (building surveyor, DDA, façade)
- Explain the lecture’s three positions: architect as subject, interpreter, and co-author of the instrument
- Connect the 1666 London rebuilding acts to today’s planning time limits, neighbour protection, and dispute mechanisms
- Place the pre-readings (Lui; Hill; Fire, Water, Building) as cases of values becoming, or failing to become, minimum standards

## Key terms

| Term | Definition (in your words) |
|------|----------------------------|
| NCC | National Construction Code — today’s instrument that classifies buildings and sets measurable minima |
| Building class (A6) | Use classification (Class 2, 3, 5, 6, 9, etc.); class + rise in storeys sets Type A, B or C construction |
| Type of construction (C2D2) | Construction type/rate required once class and storeys are known |
| Standard vs bespoke | Standard = Deemed-to-Satisfy / prescribed outcome with the building surveyor; bespoke = performance path tested with other experts |
| Instrument of law / of service | The code (and related planning/dispute rules) that enables buildings to exist; not a neutral manual |
| Subject / interpreter / co-author | Three roles: what must I do? why does this requirement exist? who gets to change its assumptions? |
| Law is provisional | Written → interpreted → amended → repealed — not optional, but not fixed |
| London Act 1666 | Rebuilding + Fire Disputes Acts — types/rates, dimensions, light, ventilation, time, neighbours, disputes, property reorganised for the city |
| Livable housing (NCC 2022) | Once-optional accessibility becoming ordinary minimum (e.g. step-free path on Class 1a, with exemptions) |

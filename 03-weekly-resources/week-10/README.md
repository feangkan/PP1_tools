## Key terms

| Term | Definition (in your words) |
|------|----------------------------|
| Code of Conduct cl. 4 | The architect must have a written agreement before providing services, with 14 required contents (a)–(n) |
| CAA 2024 | The Code of Conduct written as a contract: services, fees, changes, copyright, insurance, disputes, termination |
| D.8 Change to the Services | The architect tells the client how a scope change affects the fee, then both agree it in writing |
| Cost of Works / Total Project Cost | Cost of the building work vs. everything the client spends; the client manages the second |
| Licence to use | The client may use the design; copyright stays with the architect |
| Contract documentation | Specification, schedules and drawings, plus consultants' documents |
| AS 4120 | Code of Tendering: equal information, funding in place, no collusion, fair evaluation |
| Normalised price | A tender price adjusted so tenders compare on the same basis |

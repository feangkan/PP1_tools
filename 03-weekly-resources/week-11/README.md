## Key terms

| Term | Definition (in your words) |
|------|----------------------------|
| Order of precedence | Which contract document wins when documents conflict: special conditions, then specification, then drawings, then other incorporated documents (Schedule 3) |
| Periodic site visit | The architect checks general conformance of what has been built; the builder remains responsible for supervising the work |
| Opening up / testing | The architect may instruct work to be opened up; the contractor claims the cost, and rectifies it if it is not adequate |
| Substitution | A contractor's proposal to use something different from the documents. It changes the description of the works, so it goes through a variation, never agreed on site |
| Defects liability period | After practical completion, the architect issues defects and the builder rectifies them before the final certificate |

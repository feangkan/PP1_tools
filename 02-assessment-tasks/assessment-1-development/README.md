## How to use this for hand-drawing

1. Open [`00-a1-topics-map.md`](00-a1-topics-map.md) — the brief’s required topics, and which week feeds each one.
2. Open one week file at a time (`week-01` … `week-05`). Each file is a **design sheet**: short-form nodes, clusters, arrow labels, tensions.
3. Draw the **registration spine first** (education → logbook → APE → ARBV → CPD/PI). Everything else attaches; nothing floats.
4. Label arrows with the brief’s verbs: *enables / limits / depends upon / influences / causes / prevents*.
5. Keep versions (v01 messy → v02 reorganised). The brief marks iteration as part of the work.
6. When a node is ready for the real A1, copy it into a new hand-drawn sheet — do not edit the main `05-diagrams/assessment-1/` files from this pack.

**Style:** yellow main nodes, white expansions, green theory/A1, red tension. See `08-diagram-style/legend.md`.

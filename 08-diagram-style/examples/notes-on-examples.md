## What these examples teach for PP1

1. **Hybrid structure** — circular process core + left input + right output + radial detail.  
2. **Short-form first** — salary bands, %, role labels, stage names — not paragraphs on the canvas.  
3. **Same scaffold, different content** — Initiation / Structure / Labor / Operations / Value reused across models so comparison is readable.  
4. **Line vocabulary** — primary vs relationship vs feedback vs transform.  
5. **Colour = hierarchy** — yellow mains, white expansions, green integrated theory, blue transforms.  
6. **Full picture at the end** — after networking, the whole practice model is visible at a glance.  
7. **Optional linear strip** — a bottom “input → output” line summarises the story for presentation.

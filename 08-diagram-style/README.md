## Your method (short)

1. Build information in **short-form nodes** (keywords, not paragraphs).  
2. **Network** related nodes with line types that mean different relationships.  
3. Use **colour** for grouping / hierarchy.  
4. Layout can be **circular, mindmap, timeline, top-down, left-right**, or a hybrid.  
5. End with a **full picture** of the topic — then explain, present, cite.

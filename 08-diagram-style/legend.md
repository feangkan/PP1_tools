# Legend (reuse every week)

Copy this box onto each weekly diagram.

## Nodes

| Symbol | Name | Meaning |
|--------|------|---------|
| Yellow oval / pill | **Main node** | Core topic or primary stage |
| White rounded box | **Expansion** | Short-form detail |
| Green box | **Integrated node** | Assessment 1 / theory link |
| Blue “+ …” | **Transform** | Shift or upgrade of a practice idea |

## Lines

| Line | Name | Meaning |
|------|------|---------|
| `→` solid | **Primary** | Main flow / direct cause |
| `- - →` dashed | **Relationship** | Related influence |
| `···→` dotted curved | **Feedback** | Output returns to earlier stage |
| coloured solid | **Cross-link** | Connects clusters or weeks |
| coloured dashed | **A1 connection** | Ties to Disciplinary Matrix |

## Suggested relational labels on arrows

enables · limits · depends upon · influences · causes · prevents · feeds back into

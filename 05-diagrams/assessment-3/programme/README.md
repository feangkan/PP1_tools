# Programme / timeline workbooks (Excel, Google-Sheets importable)

| File | What it is | Use it for |
|------|-----------|------------|
| `gantt_programme_options.xlsx` | **Master reference.** Rebuilt from the reference images: Option 1 (start Sept 1958) vs Option 2 (start March 1961), best and worst case, 6-month ticks. **Not our project.** | The format to follow, and background for Part B: Option 1 = building while design is unfinished, which is what caused Scenario 1 |
| `soh_scenario1_timeline.xlsx` | **Our project**, in the timeline-board format: Scenario 1 (additional piers), built from the group's Document Register. Tab 1 **Timeline board** = lanes D0–D3 / C1–C3 with owner + checker, colour by factor, the three phases, scenario marker, 1956–1974 in half-years; tab 2 **Scenario 1 Zoom** = the variation chain month by month, 1961–62; tab 3 **Task Assignment** = each lead's tasks with a To do / Doing / Done dropdown | The A1 Timeline, and the dates that the Register and forms must match |
| `soh_board_layout.xlsx` | **Our project, one section per sheet** (looks like `../timeline/soh-timeline-scenario1.png`): **Cover** (title, legend, sheet index, how to edit) · **Design timeline** (D0–D4) · **Contract timeline** (C1–C4) — one column = one quarter, 1954–1978, lane names + years frozen, spare rows per lane · **Register** (one row per document, course sample columns) · **Event cards** (one per required form / scenario event) · **Workflow** · **Tasks** (status dropdown) · **Zoom 1961-62** (ABIC SW clock + the chain; diamonds are formulas that follow the dates) · **Events (data)** (all 83 events with source keys) | The A1 Timeline: edit section by section, print each sheet on its own page |
| `soh_board_template.xlsx` | **The same nine sheets, empty**: blank lanes, Register, cards, tasks and zoom rows | A fresh start or another scenario |

All are generated by scripts in this folder (`build_gantt.py`, `build_scenario1_timeline.py`, `build_board_layout.py`). Run with `py <script>`.

**One source of truth:** `build_board_layout.py` reads its events from `build_scenario1_timeline.py`. To change an event, edit that file, then re-run both scripts.

How `soh_scenario1_timeline.xlsx` works:
- **Scenario 1 numbers box** (top of tab 1): site possession, original PC date, SW-14 months, contract sum, SW-11 amount. Change them; the adjusted PC date and contract sum after SW-11 are formulas.
- **Blue dates** are inputs. Diamonds and bars move when you change them. Tab 2's dates are green formulas that pull from tab 1, so change dates on tab 1 only.
- **Status column**: REG = already in the Register · [F] = sourced fact · [A] = our assumption (yellow). Most [A]s are months placed inside a year the Register only gives as a year. Agree the real months as a group.
- **Flags carried over**: the CAA row must be the 2024 edition (the Register says 2019); SW-42 and SW-13 are optional forms.

To import into Google Sheets: File → Import → Upload → choose the .xlsx.

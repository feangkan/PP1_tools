# 02 — Concept index (living document)

Every concept that has appeared in more than one week's diagram pack, tracked here so overlaps get caught early instead of after 6 weeks are stacked up.

**How to use this file:** before starting a new week's diagram pack, skim this table. If a new week's source material touches something already listed here, note it in that week's `04-topics-context.md` under a "relates to" line, and add a row (or update an existing row) here once the week's pack is done. This file is updated *after* each week's pack, never before — the weekly pack itself stays scoped to that week's own sources only, per `weekly-diagram-pack.mdc`.

---

## Status key

| Status | Meaning |
|--------|---------|
| **Duplicate** | Same content redrawn — should be canonicalised, not repeated |
| **Reconciled** | Related but not identical across weeks — differences are worth noting explicitly |
| **Thread** | Same underlying question/theme, addressed from different angles |
| **Open** | Appeared once, flagged as likely to recur — watch for it |
